# Enki Agency Uniq для Mac

Локальная Mac-версия уникализатора видео и фото. Версия 2.4.1 Executive Black работает на Qt-интерфейсе и использует отдельное Python-окружение для зависимостей. Движок ffmpeg делает crop/zoom, легкие изменения цвета, скорости, FPS, шума, пересобирает кодек и чистит метаданные.

## Быстрая установка

1. Распакуй архив.
2. Открой \`Install DuckyBruto Uniq.command\`.
3. Если macOS спросит разрешение, нажми правой кнопкой по файлу и выбери Open / Открыть.

Установщик сам проверит Homebrew, Python 3 и FFmpeg. Если чего-то нет, поставит автоматически, скопирует приложение в \`~/Applications\` и откроет его. Это обычная папка Applications внутри твоего пользователя: так приложению проще обновляться без админского пароля.

## Если macOS пишет «файл поврежден»

Это не ошибка уникализатора. Telegram/macOS иногда ставит на скачанные скрипты quarantine-метку, и неподписанный установщик открывается с текстом «повреждено, переместите в Корзину».

Открой Terminal, перетащи туда распакованную папку с приложением и выполни команду ниже, заменив путь на путь к этой папке:

\`\`\`sh
xattr -dr com.apple.quarantine "/путь/к/day_xxx_uniquifier_macos"
\`\`\`

После этого снова открой \`Install DuckyBruto Uniq.command\`. Это одноразовое действие для скачанного архива.

## Как запустить без установки

Открой \`Enki Agency Uniq.app\` прямо из папки. Если FFmpeg не найден, приложение предложит установить его автоматически.

Если macOS ругается на неизвестного разработчика, нажми правой кнопкой по приложению, выбери Open / Открыть и подтверди запуск.

Если иконка появляется и сразу пропадает, запусти `start.command` или `Install DuckyBruto Uniq.command` из свежего архива. `start.command` сам пробует снять quarantine-метку и выставить права запуска.

## Как пользоваться

- Добавить видео копирует выбранные файлы в папку input.
- Уникализировать создает готовые ролики в output/videos.
- Версия 2.4.1 Executive Black публикуется через GitHub manifest, поэтому старые сборки с кнопкой обновления смогут скачать свежий архив.
- Режим instagram самый сильный и стоит по умолчанию.
- Опция Каждую копию в отдельную папку удобна, если делаешь несколько копий одного исходника.
- Опция След CapCut в MP4 добавляет CapCut-like метаданные контейнера. Это не настоящий экспорт через CapCut и не гарантия реакции алгоритмов, а технический профиль файла.

## Папки

- При запуске из распакованной папки: папки \`input\`, \`output/videos\`, \`processed\`, \`failed\` лежат рядом с приложением.
- При установке в \`~/Applications\`: рабочая папка лежит в \`~/Movies/day_xxx_uniquifier\`.
- \`input\` - исходные видео.
- \`output/videos\` - готовые уникализированные видео.
- \`processed\` - оригиналы, если включено перемещение после обработки.
- \`failed\` - резервная папка под будущую обработку ошибок.

Это не подписанное App Store-приложение, а локальный рабочий пакет. Подписанный \`.dmg\` можно собрать уже на Mac через Apple Developer/Xcode, если понадобится раздавать приложение широкому кругу людей без предупреждений macOS.

## Обновления через GitHub

Старые сборки с кнопкой `Проверить обновления` читают маленький JSON-файл `update-manifest.json` из GitHub:

\`\`\`json
{
  "version": "2.4.1",
  "zip_url": "https://raw.githubusercontent.com/Delkel/day_xxx_uniquifier/main/release/enki_agency_uniq_2.4.1_executive_black_macos.zip",
  "notes": "Что изменилось в версии"
}
\`\`\`

После создания реального GitHub-репозитория нужно прописать прямую raw-ссылку на этот JSON в `settings.json`:

\`\`\`json
{
  "updateManifestUrl": "https://raw.githubusercontent.com/USER/REPO/main/update-manifest.json"
}
\`\`\`

Когда версия в manifest станет выше текущей, приложение скачает zip, поставит зависимости, заменит себя в `~/Applications`, снимет quarantine-метку и откроет новую версию.
